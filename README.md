# Java Calculator 🧮

A simple **Calculator application built using Java Swing**.  
This project performs basic arithmetic operations with a clean GUI.

## ✨ Features
- Basic operations:
  - Addition (+)
  - Subtraction (−)
  - Multiplication (×)
  - Division (÷)
- User-friendly **Java Swing GUI**
- Supports continuous expressions (e.g., `6 + 7 + 56*2`)
- Clear button to reset input

## 🛠️ Technologies Used
- Java
- Java Swing (GUI)
